unishade.me doesn't use cookies.

Cloudflare, which hosts the site, can set a short-lived cookie of its own when it checks whether a visit comes from a bot. It's only used for that, and unishade.me never reads it. See [Cloudflare's cookie policy](https://www.cloudflare.com/cookie-policy/).
