# DLSS5 stuck on "waiting"

If DLSS5 stays on "waiting", follow these steps.

## 1. Turn off "Require DLSS"

In the Unishade menu, click the **DLSS5** tab, then turn off **Require DLSS**.

![Require DLSS turned off](assets/dlss5-require-dlss.png)

## 2. Set Unishade to use your RTX GPU

Open Windows **Settings > System > Display > Graphics > Add Desktop App** and add **Unishade.exe** from your installation folder.

![Unishade added to Graphics](assets/dlss5-exe-graphics.png)

Open its graphics options and set **GPU preference** to your **NVIDIA RTX card**. Check the GPU name before saving.

![Unishade set to use the RTX GPU](assets/dlss5-gpu-preference.png)
